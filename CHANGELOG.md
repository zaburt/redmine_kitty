# Changelog

All notable changes to Kitty are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/) and the
project uses [Semantic Versioning](https://semver.org/).

## [1.2.1] - 2026-10-13

### Fixed
- Links to wiki pages that do not exist yet were unreadable (red text on red background); they are now a pink chip with a dashed border.

## [1.2.0] - 2026-10-13

### Changed
- Orange buttons are now a pink gradient based on `#FF2BD6`, with a pink glow and a pink-to-cyan hover.

### Fixed
- Flash and error message icons overflowed to the left of the box.

## [1.1.0] - 2026-10-13

### Fixed
- Parent project link in the header breadcrumbs was invisible on the light header.

## [1.0.0] - 2026-10-10

### Added
- Initial release: a light neon theme with a cat-face logo.
- Support for Redmine 7+ (`themes/` directory).
- Header, login and favicon artwork.
